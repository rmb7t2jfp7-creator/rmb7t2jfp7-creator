# Small tools for everyday waste

**Keep useful things in use. Make everyday decisions a little clearer.**

A collection of small, open-source tools for food, repairs, shared belongings, energy, and files. Run them locally, keep your own data, and use them without an account.

| Project | What it does | Try it |
| --- | --- | --- |
| [Food Waste Ledger](https://github.com/rmb7t2jfp7-creator/food-waste-ledger) | Record discarded food and understand the weight you logged. | [Live app](https://rmb7t2jfp7-creator.github.io/food-waste-ledger/) |
| [Use It First](https://github.com/rmb7t2jfp7-creator/use-it-first) | Organize pantry stock and subtract what you have from a shopping target. | [Live app](https://rmb7t2jfp7-creator.github.io/use-it-first/) |
| [Fix-It Log](https://github.com/rmb7t2jfp7-creator/fix-it-log) | Keep repair notes, attempts, status, and recorded costs together. | [Live app](https://rmb7t2jfp7-creator.github.io/fix-it-log/) |
| [Appliance Energy Calculator](https://github.com/rmb7t2jfp7-creator/appliance-energy-calculator) | Compare estimated energy use and cost for two appliance setups. | [Live app](https://rmb7t2jfp7-creator.github.io/appliance-energy-calculator/) |
| [Borrow Tracker](https://github.com/rmb7t2jfp7-creator/borrow-tracker) | Remember what you lent or borrowed, who has it, and when it is due. | [Live app](https://rmb7t2jfp7-creator.github.io/borrow-tracker/) |
| [Duplicate File Finder](https://github.com/rmb7t2jfp7-creator/duplicate-file-finder) | Review matching file content in a folder with a read-only report. | [Run locally](https://github.com/rmb7t2jfp7-creator/duplicate-file-finder#run-it) |

### Small by design

The browser tools use plain HTML, CSS, and JavaScript with local storage and JSON backups. The Python tools need no third-party packages. Each project includes instructions, tests, and an MIT license. Export your data before changing browsers or clearing site storage.

### Make a tool more useful

Found a bug or have a feature in mind? Open an issue in that tool’s repository. Describe what you were trying to do, what happened, and the smallest change that would help. Fictional examples are welcome; keep personal records out of public issues.

---

These are initial prototypes developed with substantial AI assistance. Examples are fictional, and no adoption or environmental results have been measured. Each README explains what works today, its limitations, and possible next steps.
